# 3 范数空间
## 3.1 
范数在线性空间中，衡量向量长度的工具。

### 三个基本性质：
- **非负性与正定性 (Non-negativity & Positive definiteness)**
    $$\Vert{}x\Vert{} \ge 0$$
    
    并且当且仅当零向量 $x = 0$ 时，才有 $\Vert{}x\Vert{} = 0$。
    
- **齐次性 (Homogeneity / Absolute scalability)**
    $$\Vert{}\alpha x\Vert{} = \vert{}\alpha\vert{} \Vert{}x\Vert{}$$
    其中 $\alpha$ 为任意标量（实数或复数），$\vert{}\alpha\vert{}$ 表示它的绝对值或模长。向量放大多少倍，其范数也放大相同的倍数。
    
- **三角不等式 (Triangle inequality)**
    $$\Vert{}x + y\Vert{} \le \Vert{}x\Vert{} + \Vert{}y\Vert{}$$

### 欧式空间的二范数 (表示向量的长度)：
$$\|x\|_2 = \left( \sum_{k=1}^{n} |\xi_k|^2 \right)^{\frac{1}{2}} = (x^H x)^{\frac{1}{2}}$$
$x^H=(\overline{x})^T$ 代表共轭转置。
**情况一：实数向量**
例如：
$$x=\begin{pmatrix}3\\4\end{pmatrix}$$

因为实数的共轭还是它本身，所以：

$$x^H=x^T=\begin{pmatrix}3&4\end{pmatrix}$$

于是：

$$x^Hx=\begin{pmatrix}3&4\end{pmatrix}\begin{pmatrix}3\\4\end{pmatrix}=9+16=25$$
因此：

$$\Vert{}x\Vert{}_2=\sqrt{x^Hx}=5$$

**情况二：复数向量**

例如：

$$x=\begin{pmatrix}1+i\\2\end{pmatrix}$$

先取共轭（把 $i$ 变成 $-i$），再转置：

$$x^H=\begin{pmatrix}1-i&2\end{pmatrix}$$

计算：

$$x^Hx=(1-i)(1+i)+2\times2$$

$$=2+4=6$$

所以：

$$\Vert{}x\Vert{}_2=\sqrt{6}$$

这就是为什么书中使用 $x^H$，而不是简单地使用 $x^T$：为了让公式在复数空间中也成立。

### 无穷范数
**例3.2 连续函数的无穷范数**
在连续函数空间中，无穷范数就是在给定闭区间上，绝对值最大的函数值。
$$\Vert{}f\Vert{}_\infty = \max_{a \le x \le b} \vert{}f(x)\vert{}$$
**例3.3  无穷序列的无穷范数**
$$\Vert{}x\Vert{}_\infty = \sup_{k \in \mathbb{N}} \vert{}\xi_k\vert{}$$
数列的无穷范数，就是所有元素绝对值的上确界。 这里用sup而不用max的原因是sup可以是数列中实际不存在的元素，max代表必须在实际中存在。
 $$x=\left(\frac12,\frac23,\frac34,\ldots\right) $$  比如这个数列就没有最大值，但是有上确界1，无限接近。
无穷数列的二范数同样满足上面的三个基本性质。

向量的p范数可以写成
$$\|x\|_p = \left( \sum_{k=1}^{n} |\xi_k|^p \right)^{\frac{1}{p}} = (x^H x)^{\frac{1}{p}}$$
向量的无穷范数为向量绝对值中最大那个分量。

### 矩阵的范数
**行范数**
假设有一个矩阵
$$A=\begin{pmatrix} 1&-2&3\\ 4&5&-6\\ -7&8&9 \end{pmatrix} $$
矩阵的无穷范数(行范数)
- **逐行计算绝对值和**：
    - 第一行：$\vert{}1\vert{} + \vert{}-2\vert{} + \vert{}3\vert{} = 6$
    - 第二行：$\vert{}4\vert{} + \vert{}5\vert{} + \vert{}-6\vert{} = 15$
    - 第三行：$\vert{}-7\vert{} + \vert{}8\vert{} + \vert{}9\vert{} = 24$
- **取最大值**：
- $$\Vert{}A\Vert{}_\infty = \max(6, 15, 24) = 24$$
列范数
- **逐列计算绝对值和**：
    - 第一列：$\vert{}1\vert{} + \vert{}4\vert{} + \vert{}-7\vert{} = 12$
    - 第二列：$\vert{}-2\vert{} + \vert{}5\vert{} + \vert{}8\vert{} = 15$
    - 第三列：$\vert{}3\vert{} + \vert{}-6\vert{} + \vert{}9\vert{} = 18$
- **取最大值**：
- $$\Vert{}A\Vert{}_1 = \max(12, 15, 18) = 18$$

同一个向量空间可以定义不同的范数，使其成为不同的赋值空间。$$x=\begin{pmatrix}3\\4\end{pmatrix}$$
1-范数是 3 + 4 = 7，2-范数是$\|x\|_2=\sqrt{3^2+4^2}=5$,无穷范数是 $\|x\|_\infty=\max(3,4)=4$ 。

**后续默认对于实数向量空$\mathbb{R}^n$ 间，复数向量空间$\mathbb{C}^n$默认使用2-范数，连续函数空间$C[a,b]$使用无穷范数。**

### 范数的度量：$$
x=\begin{pmatrix}1\\2\end{pmatrix}, \qquad y=\begin{pmatrix}4\\6\end{pmatrix}
$$
$$
x-y=\begin{pmatrix}-3\\-4\end{pmatrix}

$$
$$
d(x,y)=\|x-y\|_2 =\sqrt{(-3)^2+(-4)^2}=5
$$
度量必须满足的三个性质：

1. 正定性（M₁）$d(x,y)\ge0$ 并且$d(x,y)=0\iff x=y$. 两个点之间的距离不可能为负数，如果距离为0说明两个点完全相同。
2. 对称性：$d(x,y)=d(y,x)$, x到y的距离等于y到x的距离
3. 三角不等式：$d(x,y)\le d(x,z)+d(z,y)$ .
4. 平移不变性：$d(x+z,y+z)=d(x,y)$
5. 齐次性：$d(\lambda x,0)=|\lambda|d(x,0)$,
