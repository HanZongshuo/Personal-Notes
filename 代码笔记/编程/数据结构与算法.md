# 1. 算法复杂度分析
Big (O): 没有循环的为O(1), 有一个循环为O(n), 嵌套的为O(n^2).

用来描述当输入规模n越来越大的时候，运行时间的增长速度有多快。

操作技术规则：
- 算术与逻辑运算：`+`, `-`, `*`, `/`, `%`, `==` 等
    
- 变量赋值（Assignment）
    
- 函数返回（`return`）
    
- 变量/数组元素访问（读或写内存）

## 1.1 渐进上界 Big-$O$
如果存在正常数 $c$ 和 $n_0$，使得对所有满足 $n \ge n_0$ 的 $n$，均有：

$$f(n) \le c \cdot g(n)$$

则称 **$f(n) = O(g(n))$**（或 $f(n)$ 属于 $O(g(n))$）。​

Big O 是增长的上界，Big Omega是增长的下界， Big Theta 则是当增长曲线上界和下界一致时，可以使用。


## 2. 算法正确性分析
### 1.循环不变量
用于验证算法的正确性：如果循环能停下来，得到的结果是否正确
每次循环都会改变具体的变量数值，但是变量之间的逻辑关系始终不变。

#### 2. 循环变式
证明算法的终止性：循环是否在有限步内停下来。

## 1.2 渐进下界 Big-$\Omega$
渐进下界（Lower Bound）的记号是 **大 $\Omega$（Big-Omega）**：

$$f(n) = \Omega(g(n))$$
数学定义为：存在正常数 $c > 0$ 和 $n_0$，使得对所有 $n \ge n_0$，都有 $f(n) \ge c \cdot g(n)$。

## 1.3 大 $\Theta$（Big-$\Theta$）
当渐进上界与渐进下界重合时，大θ并不一定总是存在。

证明两个函数具有紧确界关系 $f(n) = \Theta(g(n))$，本质上就是证明 **$f(n)$ 的增长阶数既不高于 $g(n)$，也不低于 $g(n)$**，被两条常数倍的 $g(n)$ 曲线“夹”在中间。

你需要明确构造出三个正数：下界系数 $c_1$、上界系数 $c_2$、起始阈值 $n_0$，使得对任意 $n \ge n_0$，不等式链恒成立：

$$c_1 g(n) \le f(n) \le c_2 g(n)$$

## 3. Case Analysis
对于同样大小的输入n，不同的输入内容会让程序运行多久。注意与Big(O) 区分。

Best Case / Worst Case 是基于除了 nn 的取值之外，其他所有可能变化来定义的。因此需要先把取值n固定住，研究不同的状态数据会不会影响不同的运行时间。

**例子：**
最好情况： 要找的节点在链表的最前面。二叉搜索树是完全平衡的树。
最坏情况： 要找的节点不在链表中。二叉搜索树退化为一条直线。

## 3.1 递归代码时间复杂度分析
###  Master Theorem
$$T(n) = \begin{cases} d & \text{若 } n \text{ 最多为某个常数} \\ aT\left(\frac{n}{b}\right) + f(n) & \text{其他情况} \end{cases}$$
其中 $f(n)$ 属于 $\Theta(n^c)$：

- 若 $\log_b a < c$，则 $T(n) \in \Theta(n^c)$
    
- 若 $\log_b a = c$，则 $T(n) \in \Theta(n^c \log n)$
    
- 若 $\log_b a > c$，则 $T(n) \in \Theta(n^{\log_b a})$

### 3.1.1 输入规模减半
```
f(n) {
    if (n <= 1)
        return;

    f(n / 2);
}
```
$$n \rightarrow \frac{n}{2} \rightarrow \frac{n}{4} \rightarrow \frac{n}{8} \rightarrow \cdots$$
$$\frac{n}{2^k} = 1$$$$k = \log_2 n$$
$$O(\log n)$$
### 二分查找
$$T(n) = T\left(\frac{n}{2}\right) + O(1)$$
$$\log_b a = \log_2 1 = 0 = c$$
$$T(n) \in \Theta(n^c \log n) = \Theta(n^0 \log n) = \Theta(\log n)$$

### 3.1.2 输入规模不变，每次都做一定工作
```
f(n) {
    doSomething();

    if (...) {
        f(n);
    }
}
```
### 归并排序
$$T(n) = \underbrace{2T\left(\frac{n}{2}\right)}_{\text{解决两个子问题}} + \underbrace{O(n)}_{\text{划分与合并的开销}}$$
最终合并的时候需要遍历一遍列表，然后进行组合。此时发现$\log_b a = \log_2 2 = 1 = c$，命中主定理第二种情况（均势平衡），最终总时间复杂度即为经典的 **$O(n \log n)$**。
### 3.1.3 输入规模扩大一倍
比如斐波那契递归，并没有出现每一次都减半的情况，因此通过使用展开法寻找规律。
尝试通过逐层代入展开，观察项的系数规律：

- $T(1) = d$
    
- $T(2) = 2T(1) + c = 2d + c$
    
- $T(3) = 2T(2) + c = 2(2d + c) + c = 4d + 3c$
    
- $T(4) = 2T(3) + c = 2(4d + 3c) + c = 8d + 7c$
    
- $T(5) = 2T(4) + c = 2(8d + 7c) + c = 16d + 15c$

$$T(n) = 2^{n-1} d + (2^{n-1} - 1) c$$
由于最高阶项为$2^n$，因此最终的紧确复杂度为：

$$T(n) \in \Theta(2^n)$$
