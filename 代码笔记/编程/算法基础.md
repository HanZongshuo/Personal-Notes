## 1.2 归并排序--分治
- 确定分界点： mid = （1+r)/2
- 首先进行：递归排序左，右
- 归并，合二为一
[数据结构合集 - 归并排序(非递归与递归算法过程, 效率分析, 稳定性分析)_哔哩哔哩_bilibili](https://www.bilibili.com/video/BV1em1oYTEFf/?spm_id_from=333.337.search-card.all.click&vd_source=dfd5ab52d1797f02d8cd2499a5d71f61)

> [!NOTE] 算法是否稳定
一个**算法的稳定性**指的是：**如果在待排序的元素中，存在两个或多个相等的元素，在排序后它们的相对顺序仍然保持不变，则该排序算法是稳定的**。
### **举个例子**

假设有以下待排序数组：
`[ (3, A), (1, B), (3, C), (2, D) ]`
这里 `(3, A)` 和 `(3, C)` 是两个相等的元素，但它们的**原始顺序**是 `(3, A)` 在前，`(3, C)` 在后。
- **如果排序后仍然是**：
    `[ (3, A), (3, C), (2, D), (1, B) ]`
    说明算法是**稳定的**，因为 `(3, A)` 依然在 `(3, C)` 前面。
- **如果排序后变成了**：
    `[ (3, C), (3, A), (2, D), (1, B) ]`
    说明算法是**不稳定的**，因为 `(3, A)` 和 `(3, C)` 的相对顺序变了。
快速排序是不稳定的，归并排序是稳定的。因为归并排序每次都会选择左侧的元素。

```C
void mergesort(int nums[],int l, int r){
    if (l>= r) return;
    int mid = l+r >>1 ;
    
    mergesort(nums,l,mid);
    mergesort(nums,mid+1,r);
    
    int k = 0, i = l, j = mid +1;  //分别指向左右部分的开头
    
    while (i<=mid && j<=r){
        if(nums[i]<= nums[j]) temp[k++] = nums[i++];
        else temp[k++] = nums[j++];      
    }

    while (i<= mid) temp[k++] = nums[i++];
    while (j<= r) temp[k++] = nums[j++];

    for (i = l, j =0; i<=r;i++,j++)
    {
        nums[i] = temp[j];
    }
}
```

## 1.3 二分法
有单调性一定可以二分，但是没有单调性并不一定不可以二分。
**假如现在数组： 1 2 2 3 3 4，求3的起始坐标，不存在的话返回-1.**

例1：寻找数组中，某个数字的起始位置
```C
#include<stdio.h>
#include<string.h>
int lower_bound(int x, int l, int r , int p[]){
    while (l<r) //左闭右开
    {
        int mid  = (l+r) >>1;
        if(p[mid]<x) l = mid+1;
        else r = mid;  //这里是包含等于的情况，因此是大于等于x都可以被保留
    }
    return r;
    
}


int upper_bound(int x, int l, int r , int p[]){ //第一个比x大的位置
    while (l<r)
    {
        int mid  = (l+r) >>1;
        if(p[mid]<=x) l = mid+1; //找到x的话也跳过这个值，因此找到的是大于x值的情况
        else r = mid;
    }
    return r; //r和l相等的时候循环结束，因此这里返回那个都可以
    
}

int main(){
    int n,q;
    scanf("%d %d",&n,&q);
    int p[n];
    for(int i = 0;i<n;i++) scanf(" %d",&p[i]);
    while (q--)
    {
        int k;
        scanf(" %d",&k);
        int l = lower_bound(k,0,n,p);
        int r = upper_bound(k,0,n,p);
        if(l == r) printf("-1 -1\n");  //相等的时候，说明不存在，返回的都是r值
        else printf("%d %d\n",l,r-1); //由于r是第一个大于x的值，因此减一

    }
    
    return 0;
}

```

#define N 100010

int m;

    l[1] = 0;

void add(int k, int x) {
    e[idx] = x;
    l[idx] = k;
    r[idx] = r[k];
    l[r[k]] = idx;
    r[k] = idx;
    idx++;
}

// 删除第k个点
void remove_node(int k) {
    r[l[k]] = r[k];
    l[r[k]] = l[k];
}

int main() {

    scanf("%d", &m);

    char op[3];
    int k, x;

    while (m--) {
        scanf("%s", op);

        } else if (strcmp(op, "L") == 0) {

## 4.5 求组合数
解法一：
可以理解为a个苹果中选取b个苹果，其中有一个蓝色苹果，那么选取其中的不包含蓝色就是从a-1剩余中选b个，以及选蓝色，从a-1个中选b-1个。
$$
根据公式：C_a^b = C_{a-1}^b + C_{a-1}^{b-1}
$$
原理就是把每一个组合数都记下来（初始化），后续输入的值直接进行查询。
```
#include<stdio.h>
#define N 2010
int c[N][N], mod =1e9+7;
void init(){
    for(int i = 0;i<N;i++){
        for(int j = 0;j<=i;j++){
            if(!j) c[i][j] = 1;
            else{
                c[i][j] = (c[i-1][j] + c[i-1][j-1])%mod;
            }
        }
    }
}
int main(){
    init();
    int m;
    scanf("%d",&m);
    while(m--){
        int a,b;
        scanf("%d%d",&a,&b);
        printf("%d\n",c[a][b]);
    }
}

解法二：乘法逆元 + 快速幂
适用范围更广泛，但是要求 mod值为质数。 根据 组合数公式 
$$
C_a^b =\binom{a}{b} = \frac{a!}{b! \cdot (a-b)!} = a!\times(b!)^{-1}\times((a-b)!)^{-1} (\bmod p)
$$
那么求逆元，我们只需要利用费马小定理，利用快速幂来求逆元。因此$(b!)^{-1}$  = $b!^{p-2}$  在mod p 前提下（p是质数）。 因此先求出来mod b利用递归的方式，然后在把逆元存到数组中
```
#include<stdio.h>
#define N 100010

typedef long long LL;
int mod =1e9+7, fact[N], infact[N];

int qmi(int a, int b, int p){
    LL res = 1;
    while(b){
        if(b&1) res = res*a %p;
        a =(LL) a*a %p;
        b>>=1;
    }
    return res;
}
int main(){
    fact[0] = infact[0] = 1;

    for(int i = 1;i<N;i++){
        fact[i] = (LL) fact[i-1]*i % mod;
        infact[i] = qmi(fact[i], mod-2, mod);
    }

    int m;
    scanf("%d",&m);
    while(m--){
        int a,b;
        scanf("%d%d",&a,&b);
        int result = (LL)fact[a]* infact[b] % mod * infact[a-b] % mod;
        printf("%d\n", result);
    }
}
```

## 4.6 容斥原理
首先根据组合数， 从n个数中选择任意多的数之和，每个数有两种，选或者不选。然后
$$
\begin{aligned}
C_n^0 + C_n^1 + \dots + C_n^n &= 2^n\\
C_n^1 + \dots + C_n^n &= 2^n - 1
\end{aligned}
$$
  容斥原理，也就是计数的加起来，偶数的减去.....
$$
|A_1 \cup A_2 \cup \dots \cup A_n| 
= \sum_{i=1}^n |A_i|
- \sum_{1 \le i < j \le n} |A_i \cap A_j|
+ \sum_{1 \le i < j < k \le n} |A_i \cap A_j \cap A_k|
- \dots
+ (-1)^{n+1} |A_1 \cap A_2 \cap \dots \cap A_n|
$$

现在给出n个数，以及m个不同质数`p1,p2...pm`，现在求1-n中可以被至少一个质数整除的个数。
根据容斥原理，计算出每一项结果，然后在根据项的个数进行加减即可。

开区间不相交问题

思路在于每次选择区间小的，这样才能选出最多的不相交区间，那么可以把右端点进行升序，如果右端点一样就看左端点，那个小。然后如果下一个的左端点大于等于当前右端点则可以选择。

相似的还有闭区间取点问题
```
#include <stdio.h>
#include<stdlib.h>
#define N 10010

typedef struct Interval{
    int l, r;
}Interval;

int cmp(const void *a, const void *b){
    Interval *x = (Interval*)a;
    Interval *y = (Interval*)b;

    if(x->r != y->r) return x->r - y->r;  //右端点从小到大
    else return y->l - x->l;  //左端点从大到小
}

int main() {
    int  n;
    scanf("%d",&n);
    Interval interval[N];
    for(int i = 0;i<n;i++){
        scanf("%d%d",&interval[i].l,&interval[i].r);
    }

    qsort(interval,n,sizeof(Interval),cmp);

    int res = 1;
    int lastL = interval[0].r;
    for(int i = 1;i<n;i++){
        if(interval[i].l>=lastL){
            lastL = interval[i].r;
            res++;
        }
    }
    printf("%d\n",res);
}
