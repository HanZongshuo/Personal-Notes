# 1 CSS部分
css可以做出动画

CSS 设计出来是为了风格能与页面结构HTML 进行分开。
内部样式的CSS在于其中用到了`<style>`标签，外部使用样式在于使用了`<link>`并且指向了css文件

如果想要只影响其中一部分的文字或者内容而非全部的话，可以通过创建类别，然后定义类别，
```
.vip {background-color: #ff6666;} style affects all elements that have set a class vip, e.g. <p class=”vip”>Very important text</p>
```

或者创建特殊的id，然后影响id。
```
#siteTitle {font-size: 3em;} style affects element whose id is siteTitle, e.g. <h1 id=”siteTitle”>The Header</h1>
```

在使用的时候：
1. 样式可以定义多个元素：比如同时定义h1，h2
2. 也可以定义嵌套关系，比如只有strong在p内部才会生效
3. 可以设置元素中的某个字母
4. 链接元素在不同情况下甚至可以出现不同的样式
5. 可以选择元素后面的元素
6. 选择该元素后面的同级元素
7. 可以为元素前面或者后面添加额外的内容而不改变HTML结构。


所有的CSS元素都有展示方式属性（display），默认的是两种`block`（块级）或者`inline`（行内）
1. 块级元素占一行`<div>`、`<p>`、`<h1>`可以设置高度。
2. 行内元素不会换行，**不能直接设置宽高**，宽高由内容决定`<span>`、`<em>`、`<strong>`
3. 当然也有介于两者之前的。并且默认属性是可以通过CSS进行更改的

异步执行
```
function A() {
    console.log("Function A has been called!")
}

function B() {
    setTimeout(() => console.log("Function B has been called!"), 3000)
}

buttonA.addEventListener("click", () => {
    A()
    B() //异步执行
    setTimeout(() => console.log("From the timeout"), 0) //异步执行
    console.log("Button A has been pressed")
})

```
有了异步执行程序之后会先执行同步任务，在执行异步任务。由于JS是单线程，如果被阻塞了那么整个线程就会被停止，因此需要使用异步处理。

    const promise = new Promise((resolve, reject) => {

        const string2 = "LUT";
        if (string1 === string2) {
            resolve(); // 成功
        } else {
            reject();  // 失败
        }
    });

}
```

同步查询与异步查询
```
const result = db.query("select x from table");
doSomethingWith(result); // 等待查询结果
doSomethingWithOutResult(); // 查询完成后才执行

-----------------------------------------
db.query("select x from table", function(result) {

# 4 Bootstrap
- **CSS 网格系统（CSS grid system, responsive layout）**  
    👉 提供响应式布局，可以根据不同屏幕大小自动调整页面排版。
    
- **UI 组件（UI components）**  
    👉 内置常见的界面元素，比如按钮、图标、导航栏等，开发者直接调用即可。
    
- **移动端布局选项（Mobile layout options）**  
    👉 针对手机和平板优化的功能，比如“抽屉式菜单”（drag out menu，即点击按钮侧边滑出的菜单）。
    
- **JavaScript 媒体选项（JavaScript media options）**  
    👉 提供与媒体（如屏幕尺寸、设备特性）相关的 JavaScript 功能，帮助实现响应式交互。
