# 梯度消失
当发生梯度消失的时候，后面单词的梯度与前面的梯度接近，也就是模型更依赖后面的单词而学不会早期的单词信息


# 梯度爆炸
梯度爆炸则会使得损失突然变大，训练发散等

## 解决办法：梯度裁剪
- **计算原始梯度：**
    
    $$\hat{\mathbf{g}} \leftarrow \frac{\partial \mathcal{E}}{\partial \boldsymbol{\theta}}$$
    
    计算损失函数 $\mathcal{E}$ 对参数 $\boldsymbol{\theta}$ 的偏导数，得到梯度向量 $\hat{\mathbf{g}}$。
    
- **阈值判断与缩放：**
    
    $$\text{\textbf{if }} \Vert{}\hat{\mathbf{g}}\Vert{} \ge \text{\textit{threshold}} \text{ \textbf{then}}$$
    
    $$\hat{\mathbf{g}} \leftarrow \frac{\text{\textit{threshold}}}{\Vert{}\hat{\mathbf{g}}\Vert{}} \hat{\mathbf{g}}$$
**$\Vert{}\hat{\mathbf{g}}\Vert{}$ 是什么？** 这是梯度的 **L2 范数（模长/几何长度）**。

> 简单理解：如果梯度向量是二维的 $\hat{\mathbf{g}} = [g_1, g_2]$，它的长度就是利用勾股定理算的 $\sqrt{g_1^2 + g_2^2}$。

例子：
- **算出的原始梯度：** $\hat{\mathbf{g}} = [6, 8]$
    
- **算长度：**
    
    $$\Vert{}\hat{\mathbf{g}}\Vert{} = \sqrt{6^2 + 8^2} = 10$$
    
- **判断：** 长度 $10 \ge 5$（超过阈值了，触发裁剪！）
    
- **按公式计算新梯度：**
    
    $$\hat{\mathbf{g}}_{\text{新}} = \frac{5}{10} \times [6, 8] = 0.5 \times [6, 8] = [3, 4]$$

# 隐藏状态
隐藏状态（Hidden State）是动态的“上下文记忆”。是由上一个时刻的状态，当前输入的词向量以及网络参数共同计算得出，对于上下文具有强相关，比如“苹果”在不同语境下的隐藏状态截然不同。


# 困惑度 Perplexity
困惑度衡量的是**语言模型对下一个词预测的不确定性**： 模型对正确词的预测概率越大，倒数越小，困惑度越小； 按照词数归一化，指数上的 $1/T$ 是为了消除文本长度对评估结果的影响，使得不同长度的句子或语料库之间具有可比性。如果一个模型的困惑度是K，  那么模型在预测下一个词的时候，平均需要从K 个难度相同的候选词中进行选择，困惑度越低，模型语言能力越强。

原始公式：
$$\text{perplexity} = \prod_{t=1}^{T} \left( \frac{1}{P_{\text{LM}}(x^{(t+1)} \mid x^{(t)}, \dots, x^{(1)})} \right)^{1/T}$$
$$\text{perplexity} = \exp(J(\theta))$$
也就是说：困惑度本质上就是**平均交叉熵损失的自然指数**

# 掩码
## 因果掩码 / 未来掩码（Causal Mask / Look-ahead Mask）
遮挡住某些不需要（或不应该）看到的数据，只保留或暴露有用的数据。在训练模型预测下一个词的时候，把后续的词注意力得分强制为无穷大（$-\infty$）。 作用于**解码器**。

## 填充掩码（Padding Mask）
用在需要批量处理的场景，在每个Batch中，每句话的长度不一样，为了能拼成同一规则的矩阵送入GPU中，补充上毫无意义的占位符。


# 多头注意力机制
**让不同的注意力头（Attention Heads）学会关注句子中不同类型的特征或语言学关系**。通过采取多头注意力机制，避免单一视角，并行设置多个Head，每个Head 可以在不同的子表达之间各司其职--有的负责指代关系，有的负责语法结构。 然后把所有head 的结果进行拼接并做线性映射。

# 因果注意力机制
模型在处理当前位置时，只允许看到“过去已经出现的 token”，不能偷看未来的 token。 如GPT，当前的token不能关注未来的token。


# 子词建模
分词面临两个极端
- **词级别（Word-level）：** 词表极大（几十万上百万），容易内存爆炸；遇到训练集里没见过的词（OOV, Out-of-Vocabulary）只能标记为 `<UNK>`，丢失语义信息。
    
- **字符级别（Character-level）：** 词表非常小（几十到几百），没有 OOV 问题，但序列过长、单字符语义过于分散，模型难以捕捉高级语义。

子词建模介于二者之间，常见词保留为完整次，罕见词或者生词拆分为已知的字词单元。
