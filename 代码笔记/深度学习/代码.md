给定一句话和当前的解析状态，预测下一步应该解析那个动作。
I love NLP

      love
      /   \
     I    NLP
 得到结果是
		love → I
		love → NLP
		ROOT → love

### class ParserModel(nn.Module):
#### 权重项
在代码中，首先定义ParserModel类， 它继承自`nn.Module` 的子类。 也就是继承了PyTorch 神经网络的所有功能， 也就可以`model.train()，model.eval(),model.parameters()`。   然后`__init__()` 函数用来定义整个神经网络的所有层（layers）和参数（parameters）。 当变量前加了self. ， 那么类里的其余函数都可以访问它。

$$\text{隐藏层权重矩阵维度} = (\text{输入特征数} \times \text{词向量维度}) \times \text{隐藏层大小}$$
采取**Xavier Initialization** 初始化方法，让每一层的输出与输入方差尽量保持一致。训练会更加稳定。 这里需要输入一个张量进来，因此采取torch.empty 创建张量

```
in_features = self.n_features * self.embed_size  
self.embed_to_hidden_weight = nn.Parameter(torch.empty(in_features, self.hidden_size)) 
  
nn.init.xavier_uniform_(self.embed_to_hidden_weight)
```

#### 偏置项
偏置项不连接两层神经元，因此没有输入项，输出项的概念。因此一般初始化为全0或者很小的随机数。

```
self.embed_to_hidden_bias = nn.Parameter(torch.empty(self.hidden_size))
nn.init.uniform_(self.embed_to_hidden_bias)
```

#### def embedding_lookup(self, w):
w 指代的是**当前句法分析器状态下提取出来的“特征词的索引”**。 假如说batch_size = 2 (同时处理 2 个句子状态), n_features = 3 (每个状态抽 3 个词)

```
w = torch.tensor([ 
	[0, 1, 2], # 句子 1 当前抽出来的 3 个特征词 ID 
	[1, 2, 3] # 句子 2 当前抽出来的 3 个特征词 ID 
])
```

然后输入词嵌入矩阵进行查找
$$\text{self.embeddings} = \begin{bmatrix} [0.1, 0.1] & \leftarrow \text{索引 0 (I)} \\ [0.2, 0.2] & \leftarrow \text{索引 1 (love)} \\ [0.3, 0.3] & \leftarrow \text{索引 2 (AI)} \\ [0.4, 0.4] & \leftarrow \text{索引 3 (NLP)} \end{bmatrix}$$

`x = self.embeddings[w]` 查表，
- 对于**句子 A** `[0, 1, 2]`：抠出第 0、1、2 行的向量 $\rightarrow$ `[[0.1, 0.1], [0.2, 0.2], [0.3, 0.3]]`
    
- 对于**句子 B** `[1, 2, 3]`：抠出第 1、2、3 行的向量 $\rightarrow$ `[[0.2, 0.2], [0.3, 0.3], [0.4, 0.4]]`

$$x = \begin{bmatrix} \begin{bmatrix} [0.1, 0.1] \\ [0.2, 0.2] \\ [0.3, 0.3] \end{bmatrix} \\ \begin{bmatrix} [0.2, 0.2] \\ [0.3, 0.3] \\ [0.4, 0.4] \end{bmatrix} \end{bmatrix}$$

#### def forward(self, w):
```
x = self.embedding_lookup(w)  # 首先查找一下x

h = torch.relu(torch.matmul(x, self.embed_to_hidden_weight)  + self.embed_to_hidden_bias)   # h=ReLU(xW + b1)

h_drop = self.dropout(h)  

logits = torch.matmul(h_drop, self.hidden_to_logits_weight) + self.hidden_to_logits_bias  # l=hU+b2​

```

## Transformer 模型
### model_solution.py
计算QKV，接受一个维度为`d_model` 的输入词向量，通过线性变换将其投影为包含 `n_heads` 个头、每个头维度为 `d_attention` 的注意力特征向量。
```
self.W_k = nn.Linear(config.d_model, self.d_attention * config.n_heads)  
self.W_q = nn.Linear(config.d_model, self.d_attention * config.n_heads)  
self.W_v = nn.Linear(config.d_model, self.d_attention * config.n_heads)
```

特征掩码：
生成一个下三角矩阵，扩充为4维常驻在模型内部，这样可以和注意力矩阵(batch, n_heads, seq_len, seq_len)进行掩码对齐。

```
[[1, 0, 0, 0],   # 第 1 个词：只能看第 1 个词
 [1, 1, 0, 0],   # 第 2 个词：可以看第 1、2 个词
 [1, 1, 1, 0],   # 第 3 个词：可以看第 1、2、3 个词
 [1, 1, 1, 1]]   # 第 4 个词：可以看第 1、2、3、4 个词
```

```
self.register_buffer(  
    "causal_mask",  
    torch.tril(torch.ones(config.context_length, config.context_length)).view(  
        1, 1, config.context_length, config.context_length  
    ),  
    persistent=False  
)
```

相关度得分：

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}} + M\right) V$$

- $Q$ 形状：`(B, heads, T, d_k)`
    
- $K^T$ 形状：`(B, heads, d_k, T)`  这里的d_k指的是单个注意力头的特征维度
    
- 得到 `att` 形状：`(B, heads, T, T)`

```
att = q @ k.transpose(-2, -1)
```
